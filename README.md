# WebMouse Server v1.0.0
> !Навайбкоженное приложение
> Превращает любой ваш смартфон в беспроводной тачпад для управления курсором ПК через браузер.

---
## Устройство

* `app.py` — Главное.
* `gui.py` — EXE приложуха.
* `server.py` — Локальный сервер на Flask.
* `static/` — (HTML/CSS/JS).

---
## Установка
1. Установите зависимости:
```bash
pip install flask pyautogui pystray Pillow
```

2. Запустите главный файл:
```bash
python app.py
```
